# 랜딩 스크린샷 교체 안내

랜딩 페이지 "이렇게 이어져요(작동 방식)" 섹션의 단계별 이미지입니다.
현재는 **회색 placeholder**가 들어가 있고, 실제 앱 스크린샷을 캡처해 **같은 파일명으로 교체**하면 됩니다.

## 파일

| 파일                 | 단계                         |
| -------------------- | ---------------------------- |
| `step1.png`          | ① 질문을 받아요              |
| `step2.png`          | ② 편하게 답해요             |
| `step3.png`          | ③ 책으로 모여요             |

## 권장 사이즈 / 비율

- **세로형(모바일 목업) 비율 9 : 19.5** — 예: `540 × 1170 px` 이상
- 형식: PNG (배경 포함)
- 너무 큰 원본은 1080px 폭 이내로 줄여 올리는 것을 권장(로딩 속도)

## 교체 방법

1. 실제 앱 화면을 캡처합니다.
2. 위 비율로 잘라 `step1.png` / `step2.png` / `step3.png` 파일명으로 저장합니다.
3. 이 폴더(`apps/web/public/landing/`)의 기존 파일을 덮어씁니다.
4. 커밋/배포하면 반영됩니다. (코드 수정 불필요)

> 경로를 바꾸고 싶다면 `apps/web/src/components/HowItWorks.tsx`의 `STEPS` 배열 `src` 값을 수정하세요.
> alt 텍스트(다국어)는 `packages/i18n/locales/{ko,en}/common.json`의 `landing.how.N.alt` 키에 있습니다.
