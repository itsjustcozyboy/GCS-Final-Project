# 토닥 (To-dak)

매일 질문 하나로 부모님의 이야기를 모아, 가족의 기록을 한 권의 책으로 남기고자 했던 프로젝트입니다.

이 저장소는 **GCS Final Project의 기획과 개발 경험을 보관하는 문서 전용 아카이브**입니다. 실행 가능한 소스 코드와 배포 설정은 제거했으며, Supabase와 Vercel 프로젝트는 종료했습니다.

## 프로젝트의 출발점

가까운 가족이어도 부모님의 어린 시절이나 삶의 선택에 관해 자세히 이야기할 기회는 많지 않습니다. 한 번에 긴 인터뷰를 진행하는 대신, 일상 속 짧은 질문과 답변이 쌓이면서 자연스럽게 가족의 이야기가 남도록 하는 서비스를 구상했습니다.

## 구상한 이용 흐름

1. 자녀가 초대 코드를 만들고 부모님과 연결합니다.
2. 관계의 분위기와 대화 깊이에 맞는 질문을 고르거나 직접 작성합니다.
3. 부모님이 글·사진·영상·음성으로 답하거나, 키워드로 답변 초안을 만듭니다.
4. 가족이 피드에서 이야기를 읽고 반응이나 후속 질문을 남깁니다.
5. 모인 답변을 주제별로 엮어 책 형태로 돌아봅니다.

## 개발했던 주요 요소

| 영역 | 내용 |
| --- | --- |
| 가족 연결 | 부모·자녀 역할과 초대 코드 기반 연결 |
| 질문 | 큐레이션 질문, 직접 작성, AI 추천 및 키워드 기반 초안 |
| 이야기 기록 | 다양한 미디어 첨부, 키워드 기반 답변 초안, 부모가 먼저 남기는 메시지 |
| 가족 피드 | 답변 열람, 반응, 후속 질문, 답변 공개 범위 설정 |
| 책 미리보기 | 공개된 답변을 주제별 챕터로 구성하는 초안 생성 |
| 사용자 경험 | 한국어·영어 지원, 모바일 중심 화면 |
| 운영 도구 | 문의 접수와 관리자 화면, 방문·가입 흐름 분석 |

외부 서비스 연동과 일부 기능은 어댑터 또는 Mock을 포함한 프로토타입 수준으로 구성했습니다. 특히 음성 전사는 실제 전사 엔진을 연동하기 전의 Mock이었으며, 책 기능은 챕터 초안과 미리보기를 중심으로 개발했습니다.

## 사용했던 기술과 구조

- **웹:** Next.js, React, TypeScript, Tailwind CSS
- **API:** tRPC, Zod, TanStack Query
- **데이터:** Prisma, PostgreSQL, Supabase
- **AI:** Gemini·Anthropic 연동과 Mock 클라이언트
- **모바일:** Expo, React Native 기반 클라이언트 구조
- **프로젝트 구성:** pnpm workspace, Turborepo 모노레포
- **배포:** Vercel, GitHub Actions

웹과 모바일 클라이언트가 API·데이터·공통 타입을 공유하도록 구성했습니다. AI, 알림 채널, 파일 저장소는 어댑터로 분리해 외부 서비스가 없는 개발 환경에서도 흐름을 확인할 수 있도록 했습니다.

## 프로젝트에서 다룬 주제

- 가족 간 대화의 부담을 줄이는 질문과 입력 방식
- 관계와 응답 흐름에 따른 질문 깊이 조절
- AI 초안을 사용자가 검토하고 수정하는 경험
- 개별 답변을 연결된 이야기와 책의 구조로 정리하는 과정
- 가족의 사적인 기록을 다루기 위한 동의, 접근 권한, 공개 범위의 중요성
